================================================================
  liber 模组加载器 - 安装说明 (Minecraft Beta 1.7.3)
================================================================

【怎么安装】（无需拖拽，手动放置，100% 可靠）

1. 打开你的 Minecraft 游戏目录，通常有两个位置：
   看你的启动器设置里的"游戏目录"，一般是：
   C:\Users\你的用户名\Documents\.minecraft
   或
   C:\Users\你的用户名\AppData\Roaming\.minecraft

2. 把这个压缩包解压。

3. 把解压出来的 [versions] 文件夹里的 [liber] 文件夹
   整个复制到你的游戏目录的 versions 文件夹里。

4. 把解压出来的 [libraries] 文件夹
   整个复制到你的游戏目录里，和已有的 libraries 合并
   （提示"是否合并/覆盖"就选"是"）。

5. 打开 PCL 启动器（PCL2），点开"版本列表"，
   应该会出现一个叫 liber 的版本，选中它点启动即可。

【常见问题】

Q: 版本列表里没有 liber？
A: 检查 liber 文件夹是否放在了正确的 versions 目录里，
   确认 liber.json 和 liber.jar 都在 liber 文件夹内。

Q: 启动器拖拽 zip 提示"无法确定此文件应当拖拽动作"？
A: 本包是"手动放置"型，不需要拖拽导入。
   直接按上面第 3、4 步复制文件夹即可。

Q: 启动时报缺 liber-loader 库？
A: 说明 libraries\dev\liber 没有复制成功，重新按第 4 步操作。
