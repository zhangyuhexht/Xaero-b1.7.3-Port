===============================================================
  Xaero 小地图 + Xaero 世界地图 (Beta 1.7.3 / liber 移植版) v1.4.6
===============================================================

【安装】
两个 jar 已放入 versions\liber\mods\：
  - xaero-minimap-1.4.6.jar     （小地图 + 路径点 + 设置，必须）
  - xaero-world-map-1.4.6.jar   （世界地图，依赖小地图）

【按键说明】
  滚轮        缩放小地图（64 / 128 / 256 / 512 格视野）
  O           小地图设置页面
  B           快速在脚下添加路径点；
              世界地图打开时 = 右键/B 在光标处创建
  M           打开 / 关闭 世界地图
  K           打开路径点管理器
  C           洞穴模式 开/关

【洞穴模式 (C 键 / 设置页)】
  在地下时显示所在高度的洞穴结构而非地表：
  黑色=实心岩石  灰色=洞穴底板  橙色=岩浆
  蓝色=地下水底  白点=矿石/沙砾
  在地表使用时显示脚下 40 格内的地面。

【死亡点】
  死亡时自动记录红色"死亡点"路径点，方便找回装备。

【设置页面 (O 键)】
  - 地图大小滑条：32 ~ 512 px 自由拖动（也支持滚轮）
  - 形状切换：方形 / 圆形
  - 小地图总开关（关掉后完全不渲染）
  - 洞穴模式开关
  - 视野范围切换按钮（64/128/256/512 格）
  - 显示生物 / 显示玩家 / 显示路径点 开关
  - 显示坐标 / 显示群系 开关
  - 一键恢复默认；自动保存到 xaero\minimap.cfg

【多人游戏】
  - 其他玩家显示为白色方块点 + 头顶玩家名
  - 可在设置中单独开关"显示玩家"

【生物标记颜色】
  红=敌对生物  浅灰白=动物  橙=其他生物

【小地图配色】
  加载原版自带却从未启用的染色贴图
  (misc/grasscolor.png 等) 按群系温度×湿度索引，
  草地/树叶呈现真正的群系色；水域按深度加深。

【世界地图】
  - 滚轮平滑缩放动画（以光标为中心锚定）
  - 右键任意位置直接创建路径点
  - 缩放 6 档（1px=8格 ~ 4px=1格），远景分级降采样
  - 路径点渐隐光柱 + 名称；玩家离屏边缘箭头
  - 光标方块高亮框、自适应比例尺、区块网格
  - 瓦片后台线程读写、原子落盘、重进自动载入

【v1.4.5 修复与改进】
  1. 【重要】小地图地形"突然变样"根因修复：b1.7.3 区块
     加载器只缓存玩家周围 17x17 窗口，窗口外区块每次查询
     都会重新随机生成（树木装饰不同）；旧版每 0.5 秒直接
     重采样导致远景地形反复变化。现改为区块瓦片缓存架构
     （每区块只采样一次，玩家附近定期刷新），画面稳定。
  2. 洞穴模式水底判定修正（此前水域被画成错误颜色）。
  3. 修复两个颜色常量手误：岩浆误为粉色改为橙红；
     未探索区误为青色改为深灰。颜色表全部重写为
     十六进制字面量，杜绝同类错误。
  4. 新增功能：洞穴模式、死亡点、共享采样核心
     （游戏与自动化测试用同一份代码，防止回归）。

【地形显示验证（v1.4.5 专项）】

  真机巡检：自动传送地表森林点 + 地下洞穴点

【v1.4.5 修复】
  1. 聊天栏/界面打开时按 M/B/K/O/C 不再误触发
     （此前 O/K 缺少界面状态守卫）。
  2. 默认小地图尺寸 128 -> 96。
  3. 【重要】玩家箭头"时有时无"根因修复：世界渲染开启的
     GL 背面剔除未在 HUD 关闭，箭头三角形朝向某些方向时
     被当作背面剔除。现 HUD 绘制期间禁用剔除，并重画为
     白底粗黑边大箭头（四朝向截图验证全部可见）。
【v1.4.5 新增】
  世界地图右键菜单：右键任意位置弹出
  [传送到此处] [添加路径点] [取消]
  传送自动落到目标点地表（单人游戏有效）。
【v1.4.5 优化】
  1. 【性能】卡顿根因修复：群系颜色采样从每方块 1 次
     噪声运算降为每区块 1 次（快约 5 倍，实测 0.22ms/区块），
     并限制每帧瓦片构建数量（小地图 4 个/周期、世界地图
     2 个/帧、附近刷新 2 个/2 秒），探索新区域不再掉帧。
  2. 【精细】每个方块叠加细微确定性明暗噪声，
     大片草地/沙地不再是一片死平色块。
  3. 【光照】洞穴模式引入真实光照：岩浆、火把附近
     会照亮周围洞穴（取天空光/方块光最大值）。
【v1.4.5 流畅度专项】
  1. HUD 每帧重复绘制消除（注入点去重，绘制开销减半）。
  2. 玩家原地不动时跳过整张地图重采样与纹理上传。
  3. 圆形蒙版去除每像素开平方（改平方比较）。
  4. 采样坐标预计算（省 3 万次/秒 Math.round）。
  5. 坐标/群系文字缓存（坐标不变不重建字符串）。
  6. 路径点列表不再每帧复制（消除 GC 压力）。
  7. ScaledResolution 每帧 2 次分配降为按分辨率缓存。
  8. 世界地图图集重建节流（瓦片增量不再每帧触发全量重建）。
【v1.4.6 流畅度专项】
  1. 采样逐像素 Long 装箱/HashMap 查询改为直映缓存
     （每帧省约 10 万次对象分配与哈希查找）。
  2. 洞穴模式采样缓存同样直映化，并修复全空气区块
     导致的"每帧反复重采样"死循环占位问题。
  3. 世界地图每帧文件系统检查（存档目录探测）移出
     空队列路径，帧内零 IO。
  4. 附近区块刷新改为旋转巡检 + 1.5ms 时间预算
     （探索后地形更新的卡顿峰值由 ~6ms 降到 ~1.5ms）。
  5. 世界地图信息栏文字/群系名按光标方块缓存。
  6. 世界地图路径点列表不再每帧复制。
  7. 修复打包问题：世界地图匿名类现在正确随世界地图
     jar 分发（此前残留于小地图 jar 中）。
